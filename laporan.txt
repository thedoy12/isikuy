LAPORAN AUDIT DAN PEKERJAAN PROJECT ISIKUY
Tanggal: 19 Mei 2026

Ringkasan:
- Project sudah dicek lewat lint, TypeScript, test, audit dependency, dan build production.
- Ditemukan 2 masalah runtime yang perlu diperbaiki.
- Keduanya sudah diperbaiki di kode lokal.

Checklist pemeriksaan:
- npm run lint: LULUS
- npm run check: LULUS
- npm run test: LULUS
- npm audit --audit-level=high: LULUS, 0 vulnerability
- npm run build: LULUS
- Cek log PM2 VPS: ditemukan error lama terkait Gemini quota dan satu error fallback index.html saat deploy.

Bug / error / kejanggalan yang ditemukan:
1. Error Gemini quota memenuhi log VPS.
   Detail:
   - Log PM2 berisi banyak error 429 RESOURCE_EXHAUSTED dari Gemini.
   - Saat quota Gemini habis, backend mencoba beberapa model dan menulis log panjang berulang.
   Dampak:
   - Log server cepat penuh.
   - Fitur AI tetap fallback ke template, tetapi server terlalu sering mencoba model yang sedang kena limit.
   Perbaikan:
   - Ditambahkan cooldown per model Gemini saat menerima status 429.
   - Log Gemini dibuat lebih ringkas supaya tidak memenuhi PM2 log.
   File:
   - api/routers/tools.ts

2. Fallback React app bisa melempar error ENOENT ketika index.html belum tersedia.
   Detail:
   - PM2 pernah mencatat error:
     ENOENT: no such file or directory, open '/var/www/isikuy/dist/public/index.html'
   - Ini bisa terjadi saat request masuk di momen deploy ketika file build belum siap/terbaca.
   Dampak:
   - User bisa melihat error server sementara.
   - Log server jadi berisi stack trace.
   Perbaikan:
   - Fallback SPA sekarang mengecek keberadaan index.html.
   - Jika file belum siap, server mengembalikan status 503 dengan pesan singkat, bukan stack trace.
   File:
   - api/lib/vite.ts

Temuan yang tidak langsung diubah:
1. Bundle frontend masih besar.
   Detail:
   - Build memberi warning chunk lebih dari 500 kB.
   - Ini bukan error fatal, aplikasi tetap berhasil build.
   Rekomendasi:
   - Nanti bisa dipisah dengan dynamic import / code splitting untuk halaman admin dan halaman besar lain.

2. Gemini quota masih bergantung pada limit akun/API key.
   Detail:
   - Cooldown sudah mengurangi spam request dan spam log.
   - Jika quota API memang habis, hasil AI akan tetap fallback ke template.
   Rekomendasi:
   - Upgrade quota/API billing atau ganti API key jika fitur AI harus selalu aktif.
